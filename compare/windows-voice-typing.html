Claude Whisper vs Windows Voice Typing

Windows has voice typing built in: press Win+H and talk. Claude Whisper is a free, open-source tray app that adds hold-to-talk on Right Ctrl and hands your speech to Claude Code’s voice dictation. Its Windows version is a first version, so this page is upfront about what it lacks.

Quick verdict

Built in, or hold-to-talk on Claude Code

Windows Voice Typing is already on your PC, has voice commands for editing, and on Copilot+ PCs cleans up grammar and fillers in English on the device. Claude Whisper on Windows is simpler still: hold Right Ctrl, speak, let go. It has no Improve on Windows yet, so its main draws are push-to-talk, the hands-free lock, History and Auto-send into Claude.

Pick Claude Whisper if

  • You want push-to-talk: hold a key, speak, let go.
  • You already use Claude Code on Windows.
  • You want a history of recent dictations to copy again.
  • You want a dictation sent straight into the Claude app (Auto-send).

Pick Windows Voice Typing if

  • You want nothing to install and no extra account.
  • You want voice commands such as “delete that”.
  • You have a Copilot+ PC and want Fluid dictation’s cleanup.
  • You want full voice control of the PC (Voice access).

Price

Both are free, with different strings

Claude Whisper

The app is free and MIT licensed. It runs on the Claude account you already use for Claude Code. You need Claude Code installed and signed in, with /voice working.

Windows Voice Typing

Included with Windows. Nothing to install.

Privacy

Microsoft, your PC, or Claude Code

Claude Whisper

Claude Code transcribes your speech under your Claude account, so the audio goes to Anthropic. Apart from update checks on GitHub when you ask, the app itself makes no network connections, and it keeps the last 30 dictations on your PC.

Windows Voice Typing

Voice typing sends voice data to Microsoft’s cloud “only to provide the service”; Microsoft says it does not store, sample or listen to recordings without your permission. Contributing voice clips is optional. Voice access runs on your PC after the language files download, and Fluid dictation uses an on-device model.

Platforms

Where each one runs

Voice typing is part of Windows 10 and 11. Voice access needs Windows 11 version 22H2 or later; Fluid dictation needs a Copilot+ PC and works in English.

Claude Whisper runs on Windows 10/11 on x64 and ARM64, as a single self-contained exe. It is not signed, so SmartScreen stops the first launch until you click “Run anyway”. The Windows app has no Improve, capsule position or Faster start yet. It also runs on macOS 14 or later.

Features

Toggle and talk, or hold and paste

Claude Whisper on Windows

  • Hold Right Ctrl, speak, let go: the text is pasted at your cursor. Right Alt or a double-tap locks hands-free.
  • History of the last 30 dictations in the tray menu.
  • Auto-send into the Claude app, and optionally consoles running Claude Code.

Windows Voice Typing

  • Win+H anywhere there is a text box; listens until you stop it.
  • Voice commands for editing and punctuation.
  • Fluid dictation on Copilot+ PCs; say “Undo that” to restore the original.
  • Voice access for controlling the whole PC by voice, offline.

Claude Whisper’s limits, plainly

  • It needs Claude Code installed and signed in to a Claude account, with /voice working. If you do not use Claude Code, it is not for you.
  • Your speech goes to Anthropic through Claude Code, under your account. It is not an offline or on-device tool.
  • Desktop only: macOS 14 or later and Windows 10/11. No iPhone or Android app.
  • The Windows app is a first version: no Improve, no capsule position and no Faster start yet.
  • The Windows build is not signed yet, so SmartScreen warns on the first launch.
  • It is unofficial: not made by, affiliated with or endorsed by Anthropic.
Fair is fair

When Windows Voice Typing is the better choice

  • You want dictation with nothing to install, no unsigned app and no extra account.
  • You want to edit by voice (“delete that”, “select that”) or control the whole PC by voice with Voice access.
  • You have a Copilot+ PC: Fluid dictation cleans up grammar, punctuation and fillers in English on the device, which Claude Whisper cannot do on Windows yet.
  • You need offline dictation: Voice access works without internet after its download.
  • You don’t use Claude Code.
FAQ

Questions about Claude Whisper and Windows Voice Typing

Why use Claude Whisper if Windows already has voice typing?

For push-to-talk on one key, a hands-free lock, a history of recent dictations, and Auto-send into Claude. If you don’t need those, Win+H is simpler.

Does Claude Whisper clean up text on Windows?

Not yet. Improve is macOS only; on Windows the text is pasted as Claude Code transcribed it. On a Copilot+ PC, Windows’ Fluid dictation does clean up English text.

Does either work offline?

Voice typing needs internet; Voice access works on device after a one-time language download. Claude Whisper always needs internet.

Can I keep using Win+H alongside Claude Whisper?

Yes. Claude Whisper uses Right Ctrl by default, which does not clash with Win+H.

Is Claude Whisper made by Anthropic?

No. It is an unofficial, independent project that works with Claude Code. It is not made by, affiliated with or endorsed by Anthropic.

Try Claude Whisper

Free and open source. If Claude Code already works on your computer, setup takes a couple of minutes.
